# Catalogue import workflows

The executable SRV importer is documented in [SRV-IMPORT.md](SRV-IMPORT.md). It follows the user’s explicit request to use source-site data and logo.

For additional catalogues, use catalogue-template.csv as a starting format. Stage and validate source IDs, supplier SKUs, category mappings, decimal prices, asset ownership, tax policy and exact stock/MOQ data before publishing purchasing workflows. Preserve provenance and unknown values. A generic admin-reviewed CSV import interface remains a later deliverable.
